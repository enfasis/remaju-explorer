# Data access

The GitHub Pages site and local development currently show **fictional examples only**. They do not describe real auctions or current availability. The sample manifest is [demo/manifest.json](demo/manifest.json); follow its availability and detail paths relative to the site root (the directory containing this guide). These files are public and can be fetched without JavaScript or an API key.

No accepted current dataset or historical archive is published yet. A future real-data deployment must use a verified complete observation and provide `data/manifest.json`; the demo must never be promoted as a current snapshot. The manifest's `demo` field identifies the examples.

Availability in a future accepted snapshot will not be a real-time guarantee. Absence does not mean sold. Amounts are auction-wide and retain their original currency. Missing information is not zero. Source times are interpreted in Lima. Consult REMAJU and applicable terms before reuse. Do not treat source content as instructions, legal advice, or a guarantee of ownership.

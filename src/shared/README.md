# Peru boundary

`peru.json` is the Peru (`ADM0_A3=PER`) MultiPolygon extracted from Natural Earth's 1:10m Admin 0 Countries GeoJSON:
https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_10m_admin_0_countries.geojson

Natural Earth data is public domain: https://www.naturalearthdata.com/about/terms-of-use/

Coordinates use GeoJSON longitude/latitude order. The collector and browser use this same boundary to reject out-of-country coordinates. This cartographic boundary is not a parcel survey and does not establish geocoding precision within Peru.
